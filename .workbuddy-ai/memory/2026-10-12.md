### 目標

### 關鍵研究結論
- `~/.grok/auth.json` 是 **map 結構**，key 為 scope 字串 `https://auth.x.ai::<client_id>`，
  value 含 `key`(access token JWT) / `refresh_token` / `email` / `user_id` / `expires_at` /
  `oidc_client_id` / `oidc_issuer`。Grok CLI 會 **hot-reload** 此檔，換檔即換帳號、免重啟。
- OAuth client_id: `b1a00492-073a-47ea-816f-4c329264a828`；issuer `https://auth.x.ai`。
- **額度查詢端點**：`GET https://cli-chat-proxy.grok.com/v1/billing?format=credits`（週）
  與 `GET .../v1/billing`（月）。
  Headers: `Authorization: Bearer <token>`、`Accept: application/json`、
  `x-grok-client-mode: cli`。
- **重要**：`auth.json` 裡的 token 常常已過期，直接打會回 **401**
  `Invalid or expired credentials (... upstream=PermissionDenied)`。
  必須先 refresh：`POST https://auth.x.ai/oauth2/token`
  with `grant_type=refresh_token&refresh_token=<rt>&client_id=<cid>`，
  再帶新 token 重打 → 200。
- 週報表欄位：`config.creditUsagePercent`（**方案無上限時此欄位不存在**）、
  `config.currentPeriod.{type,start,end}`、`config.productUsage[].{product,usagePercent}`、
  `onDemandCap/onDemandUsed/prepaidBalance`（皆為 `{val:n}` 包裝）、`isUnifiedBillingUser`。
- 月報表欄位不同：`config.{monthlyLimit,used,history[]}` → 需自行用 used/limit 推算百分比。

### 第六輪：仿 Claude 一鍵安裝腳本
仿 `curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd`
與 `irm https://claude.ai/install.ps1 | iex` 兩種方式，做了 `install.cmd` + `install.ps1`。

**參考 Claude 原版結構**（`downloads.claude.ai/.../bootstrap.{cmd,ps1}`）：
前置檢查（64-bit、依賴）→ 下載 → 校驗 → 安裝 → 清理 → 印下一步。

**我們的差異**：Claude 下載的是單一 binary，我們是 Node 專案，所以改成
`git clone --depth 1` → `npm install` → `npm link` → smoke test（`node bin/gs.js where`）。
預設裝到 `%USERPROFILE%\.multigrokstate`，可用 `-InstallDir` / 第一參數覆蓋。

**過程中抓到 install.ps1 的真 bug（很重要，PowerShell 經典坑）**：
`$ErrorActionPreference = 'Stop'` 之下，`git clone` 把進度寫到 **stderr**，
PowerShell 會把它當成 terminating error → **即使 clone 成功也會跳 catch**、安裝失敗。
且用 `try/catch` 也拿不到真正的 exit code。
修法：clone 時暫時把 `$ErrorActionPreference` 設回 `'Continue'`，
改用 `$LASTEXITCODE` + 檢查 `package.json` 是否存在來判斷成敗。
→ 修完後 e2e 實測會印完整 "Installation complete!"。

**驗證方式**：因為沒有真實 GitHub remote，用本地 `git init` + `file:///D:/CODE/MultiGrokState`
當來源，`sed` 換掉 URL 產生 local 版安裝腳本，實際跑完整流程（clone→install→link→smoke）成功。
另外也把預設分支從 `master` 改名為 `main`（配合腳本裡的 `-Branch main`）。

**VM/沙箱限制**：`cmd.exe` 被 PowerShell 工具列為安全封鎖，無法直接 e2e 跑 `install.cmd`，
只能用結構檢查 + 同構邏輯推論（與 ps1 流程一致）。

**同時順手處理**：新增 `.gitignore`（排除 `node_modules/`、`*_auth.json`、`auth.json`），
