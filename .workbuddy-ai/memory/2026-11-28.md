# 2026-11-28

## 桌面單一執行檔（macOS）

- 需求：把 GUI 打包成「單一執行檔」放桌面（同 `MultiCodexState` / `MiniMaxFlow` 的做法）。
- 指令（在 repo 根目錄）：
  ```
  dotnet publish gui/MultiGrokStateGui/MultiGrokStateGui.csproj -c Release -r osx-arm64 \
    --self-contained true -p:PublishSingleFile=true \
    -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true \
    -p:DebugType=none -o /tmp/mgs-publish
  ```
  產出 `MultiGrokStateGui`（單一 Mach-O arm64，約 48 MB），複製到桌面改名 `MultiGrokState`。
- 不加 `PublishTrimmed`（Avalonia XAML 走反射，trim 會炸）。
- 機器只有 .NET 10 runtime，但 self-contained 自帶 net8 runtime → 不依賴 `DOTNET_ROLL_FORWARD`。
- ad-hoc 簽章（`flags=0x2(adhoc)`），與其他桌面自建執行檔一致；`spctl -a` 一律 rejected，
  首次雙擊需到「系統設定 → 隱私權與安全性 → 仍要開啟」放行。
- 已知限制：`CliService` 解析順序 = `MULTIGROKSTATE_CLI` → repo 內 `bin/multigrokstate.js`
  → 全域 `MultiGrokState`。桌面副本的 base dir 不是 repo，所以只能靠全域指令；
  Finder/launchd 的預設 PATH 不含 `~/.local/bin` → 從 Finder 雙擊可能找不到 CLI。
  從終端機啟動（登入 shell PATH）則正常，實測可列出帳號與週/月額度。

## 圖示（桌面檔案 + Dock）

- 裸 Mach-O 執行檔在 Finder 是通用「exec」圖示。自訂圖示要靠
  `com.apple.FinderInfo` + `com.apple.ResourceFork`，用
  `NSWorkspace.setIcon(_:forFile:options:)` 寫入最省事（`SetFile -a C` 只設旗標，不含圖）。
  小工具：`swift /tmp/seticon.swift <icon.icns> <target>`（/tmp 不進 repo）。
  圖檔用 `gui/MultiGrokState.app/Contents/Resources/AppIcon.icns`。
  ⚠️ 用 `cp` 覆蓋新版本後要**重設一次圖示**。
- Dock 圖示：`MacDockIcon.Apply()` 原本只沿 `AppContext.BaseDirectory` 往上找
  `Assets/app-icon.png` → 單檔發佈放桌面時找不到，Dock 退回通用圖示。
  已改為找不到檔案時 fallback 到 `AvaloniaResource`
  （`avares://MultiGrokStateGui/Assets/app-icon.png`），解到
  `Path.GetTempPath()/multigrokstate-app-icon.png` 再交給 NSImage。

## 結論：桌面交付物改成 .app bundle（2026-11-28 使用者要求「不要有背景視窗」）

- **裸 Mach-O 執行檔雙擊一定會開 Terminal**（Finder 對 `public.unix-executable` 的預設開啟程式
  就是 Terminal），GUI 視窗後面永遠掛一個終端機視窗。這是 LaunchServices 行為，程式內改不掉。
- 試過在 Mach-O 塞 `__TEXT,__info_plist`（`clang -Wl,-sectcreate`）假裝成 app → `open` 靜默失敗，
  **不可行**，別再走這條。
- 正確做法：把同一個 self-contained 單檔執行檔放進 `.app`：
  ```
  MultiGrokState.app/Contents/MacOS/MultiGrokState   ← 單檔發佈產物（改名）
  MultiGrokState.app/Contents/Resources/AppIcon.icns
  MultiGrokState.app/Contents/Info.plist             ← CFBundlePackageType=APPL,
                                                        CFBundleExecutable, CFBundleIconFile,
                                                        NSHighResolutionCapable
  codesign --force --deep --sign - MultiGrokState.app
  ```
  雙擊只出 GUI 視窗、無 Terminal；圖示由 Info.plist 提供，**不需要** resource fork 那套。
  實測 `open` 啟動正常，視窗列出帳號與週/月額度。
- Finder 仍把 `.app` 顯示成單一項目，所以「一個圖示放桌面」的需求照樣滿足。
